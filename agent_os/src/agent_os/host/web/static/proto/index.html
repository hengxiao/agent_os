Lab 迭代工作流 · 三个交互原型
主题:

同一个包(dinner.planner + weather.query 外链 + 3 个用例),三份一模一样的假数据—— 只有交互模型不同。对比报告见 docs/LAB-ITERATION-FLOWS.md。

方案 A · 三栏批注驱动

既有 v003 │ 批注 → ✨生成 │ 候选 v004 (结构化只读) (列表+补充) (diff摘要+分数)

spec 原版:左侧每个字段/段落/用例都有批注锚点,批注汇聚成一轮,一次生成一个候选。 适合精细评审。

方案 B · 对话驱动

既有 ⇆ 候选(并排紧凑) ───────────────── 对话流(批注=气泡)→ 输入框

chat-native:没有独立批注面板,批注就是聊天。随手说一句就重生一版。 适合快改快走。

方案 C · 双栏 diff + 内嵌批注

既有(边注💬挂在内容旁) │ diff(红绿增删) │ 字段新旧两列 / tests +新增

GitHub PR review 心智:diff 是第一公民,批注以边注钉在内容上。 适合小步迭代、逐处确认。
