## 1. 状态机总览

### 1.1 文档全局状态

```
[idle] ──右键──→ [annotating] ──提交/取消──→ [idle]
  │                                    │
  │──点击"生成"──→ [generating] ──成功──→ [reviewing_diff]
  │                    │                    │
  │                    └─失败──→ [idle]     │
  │                                         │
  │──点击"采纳"──→ [idle] (版本+1)          │
  │                                         │
  └─点击"回滚"──→ [idle] (版本不变)         │
```

### 1.2 单条批注状态机

```
                    ┌─────────────────────────────┐
                    │                             │
                    ▼                             │
[hidden] ──右键开泡──→ [composing] ──提交──→ [pending]
   │                      │    │                    │
   │                      │    └──Esc/失焦取消──→ [hidden]
   │                      │                         │
   │                      └─编辑中──→ [composing]    │
   │                                                 │
   │──点击💬标记──→ [expanded] ←───────┘
   │                      │
   │                      └──点击✕/外部──→ [hidden]
   │
   └──悬停──→ [preview]（显示批注内容tooltip）

[pending] ──生成版本──→ [processing]
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
         [applied]     [ignored]      [outdated]
              │              │              │
              └──────都可以重新编辑────→ [composing]
```

**关键规则**：
- `applied` / `ignored` / `outdated` 的批注仍可点击 💬 标记查看和重新编辑
- 重新编辑后状态回到 `pending`，可参与下一轮生成
- `outdated` 批注编辑时，quote 区域显示「原文快照：...」提醒用户上下文已变

## 2. 右键批注：逐帧交互流程

### 2.1 场景 A：未选中文字，直接右键

```
帧 0: 用户鼠标在某段落中间位置
      光标状态：普通指针
      
帧 1: 用户右键
      → 触发 contextmenu 事件
      → 拦截浏览器默认菜单（preventDefault）
      → 在右键位置附近弹出【批注输入框】
      
      ┌─────────────────────────────┐
      │  批注                        │
      │  ┌───────────────────────┐  │
      │  │  问点什么喵，或提个意见 │  │  ← placeholder
      │  └───────────────────────┘  │
      │              [取消] [添加]   │
      └─────────────────────────────┘
      
      状态：document = [idle] → [annotating]
            annotation = [hidden] → [composing]
      
帧 2: 用户输入文字："这里语气太随意"
      → textarea value 实时更新
      
帧 3: 用户按 Enter
      → 提交批注
      → 输入框关闭
      → 右键位置插入 💬 标记（小圆标，粉色边框）
      → 该行文字添加浅粉色高亮底
      
      状态：annotation = [composing] → [pending]
            document = [annotating] → [idle]
      
帧 4: 用户鼠标移开
      → 💬 标记保持显示
      → 高亮保持显示
      
【注意】未选中文字时，批注锚定到右键点的行号+列号，quote 为空字符串
```

### 2.2 场景 B：先选中文字，再右键

```
帧 0: 用户拖选一段文字"业务需求、用户调研"
      → 选区高亮（浏览器默认蓝色选中）
      
帧 1: 用户在选区内右键
      → 拦截默认菜单
      → 在选区附近弹出批注输入框
      
帧 2: 用户输入："补充具体数据"
      
帧 3: 用户按 Enter
      → 提交批注
      → 输入框关闭
      → 选区文字从浏览器蓝色选中变为【浅粉色高亮底】（持久高亮）
      → 在选区末尾附近插入 💬 标记
      
      状态：annotation = [composing] → [pending]
      
帧 4: 用户点击文档空白处
      → 浏览器选区消失
      → 持久高亮保持
      
【注意】选中文字时，批注锚定到选区起止行列号，quote = 选中的原文
```

### 2.3 场景 C：悬停 💬 标记预览

```
帧 0: 用户鼠标悬停在 💬 标记上（无需点击）
      → 延迟 200ms 后弹出【预览浮层】
      
      ┌──────────────────────┐
      │ 💬 这里语气太随意     │
      │    L3:C12            │
      │    2 分钟前          │
      └──────────────────────┘
      
      状态：annotation = [hidden] → [preview]
      
帧 1: 用户鼠标移出
      → 浮层关闭
      
      状态：annotation = [preview] → [hidden]
```

### 2.4 场景 D：点击 💬 标记展开

```
帧 0: 用户点击 💬 标记
      → 弹出【批注卡片】（非对话框，是小卡片浮层）
      
      ┌─────────────────────────────┐
      │ 🗑  批注 · L3:C12 · 2分钟前  │
      │                             │
      │ 这里语气太随意               │
      │                             │
      │ [编辑] [删除]               │
      └─────────────────────────────┘
      
      状态：annotation = [hidden] → [expanded]
      
帧 1: 用户点击"编辑"
      → 卡片内容区变为可编辑 textarea
      
帧 2: 用户修改后按 Enter
      → 卡片关闭
      → 状态回到 [pending]
      
帧 3: 或用户点击"删除"
      → 确认弹窗："删除此批注？"
      → 用户确认
      → 💬 标记消失，高亮消失
      → 状态 → [deleted]（从列表移除）
```

### 2.5 场景 E：生成后标记状态变化

```
生成前：💬（粉色边框）

生成后：
  - 已应用 → ✅（绿色边框）+ 高亮消失
  - 已忽略 → 🚫（灰色边框）+ 高亮变淡
  - 部分应用 → ⚠️（橙色边框）+ AI 备注悬停显示
  - 锚点丢失 → ⚠️（虚线边框）+ "原文已变动"
```

## 3. 批注输入框详细规格

### 3.1 触发条件与位置

| 条件 | 行为 |
|------|------|
| 右键点在段落文字上 | 输入框出现在右键点右下方 8px 处，锚定到该行列号 |
| 右键点在 💬 标记上 | 展开已有批注卡片（编辑模式） |
| 右键点在文档空白处 | **不触发**（保持默认行为或什么都不做） |
| 已有选区 + 右键 | 输入框出现在选区右下角，锚定到选区起止 |
| 快速双击选中词 + 右键 | 同上 |

### 3.2 输入框尺寸

```
最小宽度：240px
最大宽度：min(400px, 文档右侧边界 - 输入框左边缘)
高度：auto-grow（单行 → 最多 3 行，超出内部滚动）

边框：1px solid var(--border-color)
圆角：8px
阴影：0 4px 12px rgba(0,0,0,0.12)
背景：var(--surface-color)

内部 padding：12px
```

### 3.3 输入框内部结构

```
┌─────────────────────────────────┐
│ ┌───────────────────────────┐   │
│ │                           │   │ ← textarea（placeholder: "添加批注..."）
│ └───────────────────────────┘   │
│                                 │
│  [取消]              [添加]     │ ← 按钮
└─────────────────────────────────┘
```

**快捷键**：
- `Enter`：提交（如果 textarea 不为空）
- `Shift + Enter`：textarea 内换行
- `Esc`：取消，关闭输入框
- 输入框外部点击：提交（如果已输入内容）或取消（如果为空）

### 3.4 空态处理

- 用户输入为空时按 Enter：不提交，textarea 抖动提示
- 用户输入全空格：视为空
- 用户输入超过 500 字：截断并提示"批注过长"

## 4. 生成按钮与版本状态栏

### 4.1 生成按钮位置

```
文档工具栏（预览/源码/Diff 旁边）
┌────────────────────────────────────────────────────────────┐
│ demo.test                                    v5  [🔄 生成下一版本] │
│ 预览  源码  Diff  版本历史                                  │
└────────────────────────────────────────────────────────────┘
```

### 4.2 按钮状态

| 状态 | 按钮外观 | 说明 |
|------|---------|------|
| **有 pending 批注或 chat 消息** | `🔄 生成下一版本`（主色按钮，可点击） | 正常状态 |
| **无待处理内容** | `🔄 生成下一版本`（禁用态，灰色） | 没有任何 chat 或批注可应用 |
| **生成中** | `⏳ 生成中...`（加载动画，不可点击） | 调用后端 API |
| **生成失败** | `⚠️ 生成失败，重试`（红色按钮） | 点击后重新调用 |

### 4.3 状态栏（文档底部）

```
┌────────────────────────────────────────────────────────────┐
│ 117 字 · v5 · 2 条批注待处理 · 1 条对话待应用              │
└────────────────────────────────────────────────────────────┘
```

状态栏内容动态更新：
- `v5`：当前版本号（可点击打开版本历史）
- `N 条批注待处理`：pending 状态的批注数（点击可滚动到第一个待处理批注）
- `N 条对话待应用`：chat 中未被任何版本处理过的消息数
- 生成后更新为：`v6 · 2 条已应用 · 1 条已忽略`

### 5.3 Diff 行样式

| 类型 | 前缀 | 背景色 | 说明 |
|------|------|--------|------|

- 处理结果（✅/❌/⚠️）
- AI 处理说明（如果是 ignored 或 partial）

### 5.5 操作按钮

| 按钮 | 行为 | 结果 |
|------|------|------|
| **✓ 采纳 v6** | 切换到预览视图，当前文档内容更新为 v6 | 版本号变为 v6，可继续添加新批注 |

| **✏ 在 Diff 上修改** | 允许用户直接在 diff 上编辑（高级功能） | 编辑后生成 v6'（覆盖 v6） |

## 8. 错误处理

### 8.1 锚点丢失（Outdated）

**触发条件**：文档生成新版本后，某条批注的 quote 文本在新版本中找不到匹配。

**表现**：
- 💬 标记变为虚线边框 + 橙色
- 悬停显示：`⚠️ 原文已变动，请重新定位`
- 点击展开后，quote 区域显示灰色背景：`原文快照："..."`

**用户操作**：
- 重新在文档中找到对应位置，右键新建批注
- 或删除该批注
- 或点击"尝试重新定位"（系统在新版本中模糊搜索 quote 文本）

### 8.2 生成失败

**触发条件**：后端 AI 生成超时、出错、或返回格式异常。

**表现**：
- 生成按钮从 `⏳ 生成中...` 变为 `⚠️ 生成失败，重试`
- 全局 toast 提示：`生成失败：AI 服务暂时不可用，请稍后重试`

**用户操作**：
- 点击"重试"重新调用
- 或关闭提示，继续编辑批注后再次生成

### 8.3 版本冲突

**触发条件**：两个用户同时编辑同一文档并分别生成新版本。

**表现**：
- 第二个用户点击生成时，后端检测到 baseVersion 已变化
- 返回错误：`当前文档已被更新，请刷新后重试`

**处理**：
- 前端自动刷新文档，获取最新版本
- 用户的 pending 批注保留（存储在本地）
- 用户检查最新版本后决定是否重新生成
