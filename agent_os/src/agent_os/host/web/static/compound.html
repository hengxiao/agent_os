Compound Playground
本页演示 Compound Widget 四能力(docs/COMPOUND-WIDGET.md)
① 预定义 slots:左右两栏本身是根 compound(pg-root)的两个预定义子件(compound 套 compound);
② 动态生灭:顶栏选 kind「加到左栏」= add_child(白名单 + max 闸);每卡 ✕ = remove_child(destroy);
③ 跨父转移(reparent):卡上 →/← = move_child——state 不动、path 重算(见下方 reparent 广播)、新 owner 的 provider 按新 path 重注册;
④ hard link 多视图:卡上「⧉ 链接」= 同一 instance 在右区开 tab 第二 view(child.mount_view)——改右 tab,左卡同步变(update 扇出);再点断开。页面全程用 createCompound 实现。
