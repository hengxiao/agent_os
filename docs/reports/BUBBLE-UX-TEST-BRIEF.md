# 批注气泡 UX 验收测试任务书(给 Kimi Desktop / WebBridge)

> 测试对象:Agent OS 文档编辑器的**行文级批注**(气泡)系统
> 测试入口:`http://127.0.0.1:8391/platform/`(构建号见页角,应为 **2026-08-12.4**;不符先硬刷新 Ctrl+Shift+R)
> 测试方式:WebBridge 控制真实 Chrome,逐项操作 + 截图 + DOM/坐标取证
> 目的:用户反馈「还是不对」,但现有内部测试全绿——需要外部真实环境逐条验收,定位到底哪一步偏离预期。**每条都要给出实际行为描述,不许只写"不对"**。

## 0. 前置准备

1. 打开 `http://127.0.0.1:8391/platform/`,确认页角构建号 = 2026-08-12.4;
2. 桌面点「对话」图标 → 输入框发「文档列表」→ 点卡片里的 `demo.test` → 文档窗口打开(左对话/右文档);
3. 以下测试均在右侧文档区进行。每个测试项:**操作 → 截图 → 记录实际行为 → 判 通过/偏离**。

## 1. 验收条目(每条 = 预期行为 + 取证要求)

**E1 右键原位开泡**
操作:在文档某普通段落的**中段任意位置**右键(不选文字)。
预期:气泡在**右键点的旁边**浮出(不是段落开头、不是段落下方、不盖住被点的文字);气泡标题栏显示位置徽标(形如 `L3:C18`)。
取证:截图 + 气泡 `getBoundingClientRect` 与右键点坐标。

**E2 选区右键关联**
操作:拖选一句话中的**几个字**,保持选中,右键。
预期:选中文字带**行内高亮**(浅蓝底);气泡 quote 区显示的就是选中的那几个字;位置徽标带列范围(形如 `L3:C4-L3:C20`)。
取证:截图(高亮可见)+ 高亮元素的 textContent 与选中文本逐字比对。

**E3 同一行开两个泡**
操作:同一行的**两个不同位置**各右键一次,各发一条消息。
预期:两个泡**各自独立**(内容互不串),行内有两个标记,各自在自己的位置附近。
取证:截图 + 两个泡的标题锚点串。

**E4 点泡外收起,标记留原位**
操作:开一个泡,输入几个字(不发送),点击文档空白处。
预期:泡缩成一个小圆标(💬/数字),**留在锚点位置附近**(选段末/点击点旁,不是段落开头);再点圆标 → 泡原位重开,**刚才输入的字还在**。
取证:三张截图(开/收/重开)+ 重开后 composer 内容。

**E5 点高亮重开**
操作:E2 之后收起泡,点击文档里那段高亮文字。
预期:对应的泡重开。
取证:截图。

**E6 长泡封顶内滚**
操作:在一个泡里连续对话 10+ 轮(或粘贴多条),让消息很多。
预期:气泡高度有上限(约 320px 或 45vh 内),**只有消息流内部滚动**,输入框钉在气泡底部;文档正文不被顶动。
取证:截图 + 气泡高度实测 + 消息流 scrollHeight vs clientHeight。

**E7 连发不吞**
操作:在泡里快速连发 5 条消息(不等回复)。
预期:5 条**全部**进入消息流(回复可以慢,但你的 5 条不许丢)。
取证:截图 + 消息流里用户消息条数。

**E8 删除**
操作:点泡头垃圾桶(需点两下确认),然后刷新页面。
预期:泡消失;刷新后该批注**不再出现**(后端也删了)。
取证:删除前后截图 + 刷新后状态。

**E9 滚动/切换视图后高亮仍在**
操作:E2 的高亮产生后:①上下滚动文档;②点工具条「源码」再切回「预览」。
预期:高亮始终包在原文那段文字上,不错位、不消失。
取证:两个状态的截图。

**E10 滚动独立性**
操作:左栏发很多消息,滚左栏;再滚右栏文档。
预期:左右各自独立滚动,互不带动;页面整体不滚。
取证:两栏 scrollTop 实测值。

**E11 主题切换**
操作:URL 加 `?theme=moe` 重复 E1/E2。
预期:高亮/气泡/标记在新主题下不破(无白块/无隐形文字)。
取证:截图。

## 3. 给测试执行者的备注

- 这是真实 LLM 后端,回复可能要几秒——**等待时看气泡内的 typing 指示**,不要因为回复慢误判「发送失败」;E7 只验你的消息入流,不等回复;
- 如果右键弹出了**浏览器默认菜单**而不是气泡,这本身就是重大发现,记录为 E1 偏离并截图;
- 每步操作之间留 300-500ms 间隔;所有截图存 workspace,文件名带条目号(如 `E1-open.png`);
- 测试数据随手清:E8 之外创建的批注,测完用垃圾桶删掉,保持 demo.test 干净。
